# docker 容器

## 镜像常用命令

### docker search

搜索镜像(只搜索官方仓库的，官方仓库地址：hub.docker.com)

```
docker search tomcat
```

```
docker search apache
```

### docker images

查看本地镜像列表

### docker pull

下载镜像，拉取镜像

```
docker pull tomcat:latest
```

```
docker images
```

### docker push

上传镜像，推送镜像，推到官方仓库

### docker rmi

删除镜像,直接rm不加i表示要删除容器，可以通过名称加版本来删除，或者直接通过镜像id值来删除,如果这个镜像处于运行状态的是删除不了的，比如有容器在使用这个镜像，就不能删除镜像

```
docker rmi tomcat:latest
```

```
docker rmi imageid值
```

```
docker rmi tomcat:latest tomcat:jre17-temurin-jammy
```

### docker save

导出镜像(压缩包)

```
docker save 镜像名称:版本 -o docker_nginx1.20.tar.gz
```

```
docker save nginx:1.16 -o docker.nginx1.16.tar.gz
```

### docker load

导入镜像

```
docker load -i docker_nginx1.20.tar.gz
```

## 容器的常用命令

### 容器创建与运行

创建并启动新容器

```
docker run [参数] 镜像名
```

参数

```
-d #放后台运行
-p 端口映射 #例子： -p 宿主机端口:容器端口
--name 指定容器的名字 # docker run -it --name jaden 镜像id或者名称
--link 关联另一个容器 # 了解即可
-e MYSQL_ROOT_PASSWORD #设置容器的一些属性，了解一下即可
-it 是给运行起来的这个容器分配一个终端，就可以进入到容器内部操作了,进入交互模式,后面想部署什么，直接网上搜索即可
```

### 查看容器

```
docker ps
```

```
docker container ls
```

-a / --all 查看所有容器（运行中+已停止）

```
docker ps -a
```

-q 只输出容器ID

```
docker ps -aq
```

### 启停、重启容器

优雅停止容器（推荐）

```
docker stop 容器ID/容器名
```

强制杀死容器（暴力关闭，容易损坏容器，尽量少用）

```
docker kill 容器ID/容器名
```

启动已存在的停止容器

```
docker start 容器ID/容器名
```

重启容器

```
docker restart 容器ID/容器名
```

### 删除容器

删除停止状态的容器，多个容器用空格分隔

```
docker rm 容器ID/容器名
```

-f 强制删除，可直接删除正在运行的容器

```
docker rm -f 容器ID/容器名
```

删除全部容器

```
docker rm -f $(docker ps -aq)
```

### 容器监控

查看容器内部进程

```
docker top 容器ID/容器名
```

实时查看容器CPU、内存等资源占用

```
docker stats
```

### 进入容器内部执行命令

-it 交互式终端 

方式1：直接执行单条命令，执行完返回宿主机

```
docker exec -it 容器ID ls 
```

方式2：进入容器终端（常用）

```  
docker exec -it 容器ID /bin/bash
```

部分精简镜像无bash，改用 sh 

``` 
docker exec -it 容器ID /bin/sh 
```

exit 退出容器终端  

注意：很多轻量化容器缺少ifconfig、ps、ip addr等工具，需要手动安装

### 查看容器 IP 信息

查看所有容器名称 + IP（适用于默认bridge网络）

```
docker inspect -f '{{.Name}} => {{.NetworkSettings.IPAddress }}' $(docker ps -aq)
```

兼容多网络模式，标准写法

```
docker inspect --format='{{.Name}} - {{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' $(docker ps -aq)
```

搭配grep过滤指定容器

```
docker inspect --format='{{.Name}} - {{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' $(docker ps -aq) | grep 容器名/ID
```

### 端口映射 & 网络访问示例

 -d 后台运行；

-p 宿主机端口:容器端口 

宿主机80端口 → 容器80端口

```
docker run -d -p 80:80 nginx
```

网络测试命令

 -I 只获取HTTP响应头

```
curl -I http://容器IP
```

宿主机查看监听端口（观察docker端口映射）

```
netstat -lntup
```

## docker-compose

docker-compose是批量管理docker容器的工具

常用docker-compose命令

```
#创建并启动
docker-compose up -d # 启动之后就可以通过浏览器访问了
#停止并删除
docker-compose down
#重启
docker-compose restart
#停止
docker-compose stop
#启动
docker-compose start
```
